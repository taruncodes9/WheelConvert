How It Works in 3 Steps

Effortless file manipulation with zero context switching.

1

Select Your File(s)

Click any image, PDF, or Word document inside Windows File Explorer. Works with single or multiple selections.

2

Press the Hotkey

Press Ctrl+Shift+Space. The radial pie menu instantly appears centred exactly where your mouse is.

3

Pick & Done

Hover to choose format (PNG, JPG, PDF, DOCX, TXT), crop, or compress. Converted files are saved right next to your original file.
